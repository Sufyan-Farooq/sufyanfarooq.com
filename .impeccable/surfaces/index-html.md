## Direction contract

THESIS: The portfolio is a working ops console, not a brochure: it proves operations skill by checking its own services live. It refuses the default dev-portfolio hero (portrait, gradient, skill-icon grid) and the neon-on-black hacker costume.

OWN-WORLD: Warm graphite ground, bone-white ink, one signal-amber accent used like an alert lamp; status green/red appear only for real measured state. Archivo (width axis: expanded for display, normal for text) plus Martian Mono strictly for measured data, timestamps and commands. Hairline panel rules, square corners, tabular numerals.

STORY: Visitor reads the claim, watches the status board resolve real checks, scans the Digival log of problem to outcome, sees shipped apps and AI automations, sees how this site deploys, then downloads the CV or writes.

FIRST VIEWPORT: Top status strip (name, nav, Jeddah clock, CV). Left 7 columns: expanded headline "I keep systems running and automate the rest.", two-line lead, availability line, Download CV (amber) and Contact. Right 5 columns: status board panel listing six live services with HTTP code, latency, checked-ago, resolving on load.

FORM: Ops status board, user-pinned direction (option 1 of the presented list); seed key: user-pinned, no roll.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
